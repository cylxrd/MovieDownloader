# Movie Downloader

Приложение для Windows, которое скачивает видео с YouTube и других поддерживаемых сайтов.

## Возможности

- загрузка видео с YouTube и других видеохостингов;
- выбор качества и формата MP4/MKV;
- встроенное подключение YouTube;
- поиск и предварительный просмотр видео;

## Установка

1. Откройте раздел **Releases**.
2. Скачайте **MovieDownloader_Setup_4.2.6.exe**.
3. Запустите установщик
4. При первой установке потребуется подключение к интернету.

Windows SmartScreen может показать предупреждение «Неизвестный издатель», поскольку установщик пока не подписан цифровым сертификатом.

## Версия

Текущая стабильная версия: **4.2.6**.
